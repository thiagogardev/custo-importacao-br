## [0.1.0] - 2026-11-14

### Adicionado
- Custo nacionalizado de 1 kg de qualquer NCM e teto de preço nacional, só com dados abertos e oficiais
  (Comex Stat, TEC da Resolução Gecex nº 272/2021, TIPI e PTAX).
- CLI (`npm run ncm`) e uso como biblioteca.
- Testes automáticos no GitHub Actions (Node.js 20 e 22) com verificação de tipos.
